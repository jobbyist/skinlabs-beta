# SkinLabs Beta

A modern skincare guide application built with React, TypeScript, and Vite.

## 🚀 GitHub Pages Deployment

This repository is configured for automatic deployment to GitHub Pages with a custom domain `skinlabs.co.za`.

### Deployment Setup

1. **GitHub Actions Workflow**: The `.github/workflows/deploy.yml` file contains the CI/CD pipeline that:
   - Builds the application on every push to the `main` branch
   - Deploys the built static files to GitHub Pages
   - Handles the custom domain configuration

2. **Custom Domain Configuration**: 
   - `CNAME` file in `/public` directory specifies the custom domain
   - DNS must be configured to point `skinlabs.co.za` to GitHub Pages

3. **Static Site Optimization**:
   - `.nojekyll` file prevents Jekyll processing
   - `404.html` handles client-side routing for the React SPA

### Build Process

```bash
# Install dependencies
npm install

# Build for production
npm run build

# Build output is in ./dist/public/
```

### Development

```bash
# Start development server
npm run dev

# Start production server (requires build first)
npm start
```

### DNS Configuration Required

To complete the custom domain setup, configure DNS for `skinlabs.co.za`:

#### For GitHub Pages with custom domain:
1. Add CNAME record: `skinlabs.co.za` → `jobbyist.github.io`
2. Or add A records pointing to GitHub Pages IPs:
   - `185.199.108.153`
   - `185.199.109.153`
   - `185.199.110.153`
   - `185.199.111.153`

#### Repository Settings:
1. Go to Repository Settings → Pages
2. Source: Deploy from a branch → `gh-pages`
3. Custom domain: `skinlabs.co.za`
4. Enforce HTTPS: ✅

## 📁 Project Structure

- `/client` - React frontend application
- `/server` - Express.js backend (for development)
- `/public` - Static assets (icons, manifest, CNAME, etc.)
- `/dist/public` - Built static site (generated by Vite)
- `/.github/workflows` - GitHub Actions CI/CD configuration

## 🛠️ Technologies

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI
- **Routing**: Wouter
- **Build**: Vite
- **Deployment**: GitHub Actions + GitHub Pages
