# SkinLabs Beta

A modern skincare guide application built with React, TypeScript, and Vite.

## 🗄️ Database Setup

This application uses PostgreSQL with Drizzle ORM for database management.

### Environment Setup

1. Copy the environment example file:
```bash
cp .env.example .env
```

2. Generate secure keys for your environment:
```bash
npm run generate-keys
```

3. Update `.env` with your actual database credentials and API keys.

📖 **For detailed setup instructions, see [docs/ENVIRONMENT_SETUP.md](docs/ENVIRONMENT_SETUP.md)**

### Database Commands

```bash
# Generate a new migration from schema changes
npm run db:generate

# Apply migrations to the database
npm run db:migrate  

# Push schema changes directly (development only)
npm run db:push

# Reset database and rerun migrations
npm run db:reset

# Seed database with comprehensive content
npm run db:seed
```

### Seed Data

The application comes with comprehensive seed data:

- **50+ Articles**: Skincare guides, ingredient explanations, routine guides, local brand spotlights
- **100+ Product Recommendations**: Curated products from SA retailers with ratings and affiliate links  
- **20+ Current Deals**: Live deals from Clicks, Dis-Chem, Takealot, and local brands

Run `npm run db:seed` to populate your database with this content.

### Migration System

The database uses Drizzle Kit for migrations:

- Migration files are stored in `/migrations`
- Schema is defined in `/shared/schema.ts`
- Seed data is in `/seeds` directory
- Seeding script is in `/scripts/seed.ts`

## 🚀 GitHub Pages Deployment

This repository is configured for automatic deployment to GitHub Pages with a custom domain `skinlabs.co.za`.

### Deployment Setup

1. **GitHub Actions Workflow**: The `.github/workflows/deploy.yml` file contains the CI/CD pipeline that:
   - Builds the application on every push to the `main` branch
   - Deploys the built static files to GitHub Pages
   - Handles the custom domain configuration

2. **Custom Domain Configuration**: 
   - `CNAME` file in `/public` directory specifies the custom domain
   - DNS must be configured to point `skinlabs.co.za` to GitHub Pages

3. **Static Site Optimization**:
   - `.nojekyll` file prevents Jekyll processing
   - `404.html` handles client-side routing for the React SPA

### Build Process

```bash
# Install dependencies
npm install

# Build for production
npm run build

# Build output is in ./dist/public/
```

### Development

```bash
# Start development server
npm run dev

# Start production server (requires build first)
npm start
```

### DNS Configuration Required

To complete the custom domain setup, configure DNS for `skinlabs.co.za`:

#### For GitHub Pages with custom domain:
1. Add CNAME record: `skinlabs.co.za` → `jobbyist.github.io`
2. Or add A records pointing to GitHub Pages IPs:
   - `185.199.108.153`
   - `185.199.109.153`
   - `185.199.110.153`
   - `185.199.111.153`

#### Repository Settings:
1. Go to Repository Settings → Pages
2. Source: Deploy from a branch → `gh-pages`
3. Custom domain: `skinlabs.co.za`
4. Enforce HTTPS: ✅

## 📁 Project Structure

- `/client` - React frontend application
- `/server` - Express.js backend (for development)
- `/public` - Static assets (icons, manifest, CNAME, etc.)
- `/dist/public` - Built static site (generated by Vite)
- `/.github/workflows` - GitHub Actions CI/CD configuration
